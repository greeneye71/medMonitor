# medMonitor v2 (Fedora) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sostituire medMonitor v1 (Dash + FastAPI + TinyFlux) con un'unica app FastAPI+SQLite installabile su Fedora via Podman Quadlet.

**Architecture:** Un processo uvicorn con: client MQTT (paho, thread proprio) che aggiorna `sensors.last_*`; APScheduler (BackgroundScheduler) con job campionamento 10 min, outbox 1 min, archivio 03:00; logica allarmi pura in `monitor.py`; UI Jinja2+HTMX+ECharts servita dallo stesso processo.

**Tech Stack:** Python 3.12, FastAPI, uvicorn, Jinja2, HTMX, ECharts, sqlite3, APScheduler 3.x, paho-mqtt 2.x, aiosmtplib, PyYAML, itsdangerous.

**Spec:** `docs/superpowers/specs/2026-10-08-fedora-v2-design.md`

## Global Constraints

- Intervallo campionamento fisso 10 min, allineato a :00/:10/…
- Default settings: `alarm{consecutive_samples:2, offline_minutes:120, battery_percent:20}`, `presets{fridge 2..8, freezer -25..-15}`, `archive{retention_days:180}`, `smtp{port:587, security:"starttls"}`.
- Orari salvati UTC ISO-8601, mostrati `Europe/Rome`.
- UI in italiano, nessuna CDN (asset in `app/web/static/vendor/`).
- Porta UI default 8090 (mai 8000), scelta in `install.sh`.
- Email batteria: solo apertura, chiusura con isteresi Y+5 senza email.
- Nessun DB server: solo `sqlite3` stdlib, WAL.

## Review Focus

1. Payload MQTT malformato / non JSON / senza `temperature` → ignorato senza crash del thread MQTT (test in Task 4).
2. Sensore offline durante sequenza fuori range → `consecutive_out` invariato, nessuna apertura TEMP spuria (test Task 3).
3. SMTP non configurato (host vuoto) → outbox resta in coda, nessuna eccezione nel job (test Task 5).
4. Archivio eseguito due volte sullo stesso mese → append, nessun duplicato dell'header (test Task 6).
5. Form soglie con min ≥ max o valori non numerici → errore mostrato, nessun salvataggio (test Task 8).
